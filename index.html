中央極限定理 (Central Limit Theorem)

什麼是中央極限定理？

中央極限定理告訴我們：從任何一個母體（不論其形狀是均勻、偏態還是雙峰）中，隨機抽取大小為 n 的樣本。當 n 夠大時（通常 n ≥ 30），這些「樣本平均數」的分佈將會趨近於一個常態分配 (Normal Distribution，即鐘形曲線)。
這就是為什麼常態分配在統計學中如此重要，因為它讓我們能在不知道母體真實形狀的情況下，仍能進行推論！

設定與操作

每次從母體中抽出 n 個數據，並計算其平均值。
