## 🧐 什麼是中央極限定理？為什麼它很重要？

想像一下，不管我們抽查的母體分佈長得有多奇怪（可能是呈不規則的高低起伏、一邊倒的偏態，甚至是雙峰形狀）：

* 當我們每次隨機抽出一定數量的樣本（例如 $n = 30$ 個數據）並算出它們的平均數。
* 重複這個抽樣過程很多次，把這些「樣本平均數」全部畫成圖表。
* **奇蹟發生了！** 這些平均數的分佈竟然會乖乖地排成一個完美的「鐘形曲線」（常態分配）！
* **理論樣本平均數**：$\mu_{\bar{x}} = \mu$
* **理論標準差（標準誤）**：$\sigma_{\bar{x}} = \frac{\sigma}{\sqrt{n}}$



這就是中央極限定理。它就像是統計學界的魔法，讓我們在面對未知的大自然或龐大數據時，依然能夠放心地進行科學推論與預測。

## ✨ 網頁有什麼好玩的特色？

1. **多樣的母體分佈任你選**
* **常態分配 (Normal)**：標準的對稱分佈。
* **均勻分配 (Uniform)**：每個數值出現機率都一樣平坦的分佈。
* **指數分配 (Exponential)**：嚴重偏向某一邊的偏態分佈。
* **雙峰分配 (Bimodal)**：有兩個山峰的分佈。
* *（你可以親自切換看看，證明不管起點怎麼變，結果通通都會收斂成鐘形曲線！）*


2. **自由調整樣本數（$n$）**
* 提供直覺的滑桿，讓你自由調整每次抽樣的樣本大小（從 $10$ 到 $200$，預設 $30$）。
* 觀察看看：當樣本數變大時，標準誤變小了，圖表會發生什麼變化？


3. **一鍵抽樣，見證奇蹟**
* 按一下按鈕，就能體驗抽樣 $1$ 次、$10$ 次、$100$ 次、$1,000$ 次，甚至瞬間抽取 **$10,000$ 個樣本**！
* 看著直方圖與紅色的「理論常態曲線」完美疊合，非常療癒且具教育意義。
