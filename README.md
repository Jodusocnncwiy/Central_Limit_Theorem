## 🧐 中央極限定理在說什麼？

從一個母體中每次隨機抽出 n 個值，算出樣本平均數 x̄；重複很多次，把所有 x̄ 畫成直方圖，就得到 x̄ 的**抽樣分配**。

* x̄ 的平均數等於母體平均數：$\mu_{\bar{x}} = \mu$
* x̄ 的標準差（**標準誤**）會隨 n 變小：$\sigma_{\bar{x}} = \dfrac{\sigma}{\sqrt{n}}$
* 只要 n 夠大，不論母體是什麼形狀，x̄ 的抽樣分配都會接近常態分配 $N(\mu, \sigma^2/n)$

「n 要多大才夠」取決於母體有多偏，n ≥ 30 只是經驗法則，這也是網頁第 5 頁要讓學生親眼看到的重點。

## 🗂️ 六個分頁

| 分頁 | 學生會做什麼 |
|---|---|
| 1 先猜一猜 | 看著右偏的超商消費金額分配，預測「每組 30 位顧客的平均」會長什麼樣子（答案在第 4 頁揭曉） |
| 2 一次抽樣 | 慢動作抽出一組 n 個值，看它們變成一個 x̄、落進直方圖；也可以自動連續抽 |
| 3 抽樣分配 | 一次抽 100～10,000 組，比較直方圖與理論常態曲線，對照 μ 與 σ/√n 的理論值和實驗值 |
| 4 n 的影響 | 同一個母體在 n = 1、2、5、10、30、100 下的 6 張小圖並排，看形狀變常態、寬度依 √n 縮小 |
| 5 條件與迷思 | 用極端右偏的母體說明 n = 30 不一定夠；整理三個使用條件與三個常見迷思 |
| 6 自我檢測 | 6 題選擇題，作答後立即顯示解析與得分 |

每頁都有「動手試試」任務；研究所延伸內容（σ/√n 的推導、有限母體校正、偏態與峰態的收斂速度、Berry–Esseen 定理、Cauchy 反例）放在虛線摺疊框，預設收起。

## 🧪 五個母體情境

| 母體 | 形狀 | 設定 |
|---|---|---|
| 手搖飲每杯實際容量 | 常態 | μ = 700 ml，σ = 15 ml |
| 公車等候時間 | 均勻 | 0～20 分鐘，μ = 10，σ ≈ 5.77 |
| 超商單筆消費金額 | 右偏（指數分配） | μ = σ = 120 元，偏態 2 |
| 外送送達時間 | 雙峰 | 兩群各半：約 20 分鐘與 45 分鐘，σ ≈ 13.46 |
| 網購單筆訂單金額 | 極端右偏（對數常態分配） | 中位數 600 元，μ ≈ 1,233 元，偏態約 11.2 |

每組樣本數 n 可在 1～500 之間調整。抽樣使用固定亂數種子，課堂上每次開啟的結果都相同；按「換一批亂數」可以換一組新的模擬結果。

> 教學用模擬：五個母體的參數為虛構設定，僅供課堂示範。
